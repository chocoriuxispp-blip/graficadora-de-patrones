# graficadora-de-patrones
Programa en Python para generar, analizar y comparar sucesiones matemáticas.

Descripción
Este proyecto permite configurar y comparar tres sucesiones matemáticas:
- Sucesión aritmética.
- Sucesión geométrica.
- Sucesión recurrente.
El programa genera los términos de cada sucesión, calcula sus sumas acumuladas y presenta los resultados mediante tablas y una gráfica comparativa.

Objetivo
Analizar cómo influye la regla de formación de una sucesión en su crecimiento y en la suma acumulada de sus términos.

Herramientas utilizadas:
- Python
- Matplotlib
- Visual Studio Code

Requisitos
Tener Python instalado y contar con la biblioteca Matplotlib.

Instalación
1. Descargar o clonar este repositorio.
2. Abrir una terminal en la carpeta del proyecto.
3. Instalar las dependencias:
    python -m pip install -r requirements.txt

Ejecución
Ejecutar el siguiente comando desde la carpeta del proyecto:
    python sucesiones.py
El programa solicitará la cantidad de términos y los parámetros necesarios para configurar las tres sucesiones.

Funcionalidades
- Generación de sucesiones aritméticas, geométricas y recurrentes.
- Configuración independiente de cada sucesión.
- Cálculo de términos y sumas acumuladas.
- Tablas individuales y comparativas.
- Resumen de resultados.
- Gráfica comparativa mediante Matplotlib.
